## 📖 Dokumentasi Project

Aplikasi Expense Manager yang dibuat dengan Flutter ini dirancang untuk membantu pengguna mencatat pemasukan, 
pengeluaran, serta memantau statistik keuangan pribadi. Ideal untuk latihan Flutter dan pengelolaan data yang sederhana.
